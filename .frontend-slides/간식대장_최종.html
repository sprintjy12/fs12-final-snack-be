02 · 프로젝트 AWS 구성

EC2 · Nginx · RDS · Cloudflare

  • 애플리케이션 실행 서버로 Amazon Linux 기반 EC2를 사용했으며, snack 디렉토리 내부를 frontend와 backend 디렉토리로 분리.
  • Nginx의 Reverse Proxy를 이용해 요청 경로에 따라 포트를 분기하여, 하나의 EC2 인스턴스에서 프론트엔드와 백엔드 애플리케이션을 함께 서비스하도록 구성.
  • / 요청은 Next.js가 실행되는 3000번 포트로, /api 요청은 Express가 실행되는 4000번 포트로 전달되도록 설정.
  • 데이터베이스는 PostgreSQL을 사용, 외부에서 직접 접근할 수 없도록 Private Subnet에 구성했으며, EC2의 백엔드 서버에서만 5432번 포트를 통해 접근하도록 설정.
  • 가비아에서 구매한 도메인 fs12-team2-snack.shop을 Cloudflare와 연동하고, DNS 및 SSL/TLS 설정을 통해 HTTPS 보안 접속 환경을 구성.

02 · Member

회원 탈퇴 · 복구

Soft Delete

Soft Delete 기반 회원 관리

사용자를 DB에서 삭제하지 않고 상태를 변경하는 Soft Delete 방식 적용

ACTIVE
↓ 탈퇴
WITHDRAWN
+ withdrawnAt 기록

탈퇴 시 함께 처리

  • 회원 상태 → WITHDRAWN
  • withdrawnAt 기록
  • 대기 중인 구매 요청 취소
  • 장바구니 삭제
  • Refresh Token 전체 삭제

→ 탈퇴 직후 기존 로그인 세션까지 무효화

DB에서도 회원 상태와 withdrawnAt을 별도로 보존하도록 설계되어 있다.

Recovery Policy

회원 복구 정책

단순 상태 변경이 아닌 운영 정책 기반 복구 기능으로 구현

복구 요청 ↓ SUPER_ADMIN 확인 ↓ 같은 회사 확인 ↓ WITHDRAWN 상태 확인 ↓ 탈퇴 후 7일 이내 확인 ↓ ACTIVE 복구

복구 조건

  • 탈퇴 후 7일 이내
  • SUPER_ADMIN만 가능
  • 같은 회사 회원만 복구 가능
  • 이미 ACTIVE 상태면 복구 불가
  • SUPER_ADMIN은 탈퇴·복구 대상에서 제외

복구 대상 조회도 서버에서 제한

회원 관리 화면에는 ACTIVE 회원 + 복구 기간이 남아있는 WITHDRAWN 회원만 조회

→ 복구 기간이 지난 사용자는 UI 단계까지 내려오지 않도록 서버에서 차단

최고 관리자가 회원 목록 조회, 초대, 권한 변경 및 회원 관리 기능을 담당한다는 기본 요구사항과도 연결된다.

클라이언트 ➔ 서버 사이드 검색

초기 방식 (Client-side)

  • 로컬 필터링 구현
  • 검색 상태가 URL에 남지 않아 새로고침 및 URL 공유 시 유지 불가

개선 방식 (Server-side)

  • URL 쿼리 파라미터(search)로 검색 상태 관리 (새로고침/공유 시 상태 유지)
  • 서버에 검색 조건을 전달하여 필요한 데이터만 조회

01 · Cart

장바구니 수량 변경 성능 및 UX 개선

01 · Problem

문제 상황

  • 초기 설계
    버튼을 누를 때마다 증감값(+1, -1)을 서버로 즉시 전달하는 방식
  • 발생 문제
    +, - 버튼을 누를 때마다 매번 API 요청이 발생하여, 수량을 빠르게 변경할 때 반응이 느려지는 문제 발생
02 · Solution

해결 방안

  • 디바운스
    500ms 디바운스 적용. 버튼을 연속으로 빠르게 눌러도 매번 호출하지 않고, 마지막 입력 후 500ms가 지나면 최종 누적값(예: +3)으로 단 1회만 요청
  • 낙관적 업데이트
    서버 응답을 기다리지 않고 화면의 수량을 먼저 즉시 변경하여 사용자 반응 속도 개선. 요청 실패 시 기존 상태로 롤백(Rollback) 처리
  • 트랜잭션
    서버 단에서 수량 조회부터 계산, 저장까지 하나의 작업(트랜잭션)으로 처리하여 데이터 정합성 확보
03 · Result

개선 결과

  • 디바운스로 불필요한 API 요청 감소
  • 낙관적 업데이트로 사용자 반응 속도 개선
  • 트랜잭션으로 서버 데이터 안정성 확보
